Chest Tracker 1.1.3 refines the Ledger squad display.

- Only the current streak holder shows a fire SVG and streak count. Other squad rows have no streak marker.
- Before anyone has an active streak, one grey idle flame is shown beside you.
- A crown SVG appears immediately to the left of the player with the most chests opened this game.
- Ties use the existing stable scoreboard order to show one crown. No crown appears while all game counts are zero.

Installed copies receive this update through the startup update check.
