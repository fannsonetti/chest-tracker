# Compact MiniHUD proposals

The revised concepts are hand-authored SVG vectors: no image generator, embedded raster data, textures, gradients, glow, or particle effects.

Design brief: compact, minimalist, monochrome gaming overlays with readable personal and inclusive team counts, thin SVG line icons, quiet dividers, and a small recap. Show actual 184px overlay widths.

- A Outline: personal/team stats plus roster, 184 × 140.
- B Inline: essentials only, 184 × 64.
- C Ledger: squad table, 184 × 122.
- Shared recap: small per-player counts and best consecutive-opening streak.

All standalone designs and the comparison board are in [designs](designs/). The earlier bitmap concepts remain available in Git history.
